# 第十七部分 · 公益板块集成

## 背景

侄女的平行世界平台有公益板块（儿童、环保等）。「银发星球」作为独立公益品牌，同时和侄女公益板块互相站台。

## 集成方案

### 第一阶段（MVP）：互相导流

- 侄女平台公益页展示「银发星球」项目，用户可以捐款或购买服务赠送给老人
- 「银发星球」品牌页底部标注：「生态合作伙伴：XXX（侄女平台）」——互相背书
- 通过 URL UTM 参数追踪互相导流的转化

### 第二阶段：嵌入式集成

- 当侄女的平行世界上线后，「银发星球」作为「银发公益区」整体嵌入
- 通过 iframe 或独立子域名实现
- 共享用户登录态（SSO）

## 公益项目页（在 silver-planet 域内）

URL: `/charity`

页面内容：

1. 头图 + 标语：「让每一位老人都不孤单」
2. 当前进行中的公益项目列表（来自 CharityProject 表）
3. 每个项目卡片显示：
   - 项目封面图
   - 标题、简介
   - 募集进度（已募集 / 目标）
   - 受益老人数
   - 合作伙伴标签
4. 捐赠入口（接微信支付）
5. 捐赠者墙（匿名/署名可选）

## 企业 CSR 接口

为企业捐赠预留接口：

- 企业可以批量购买「银发星球」服务赠送给社区老人
- 系统生成定制化的捐赠证书 PDF
- 企业 logo 可展示在受益老人的服务页面
- 后台数据可导出供企业作 CSR 报告使用

## 互相站台的技术实现

1. 在落地页 footer 添加合作伙伴 logo 与链接
2. 在合作伙伴侧也展示「银发星球」入口
3. 用户从合作伙伴跳转过来时，自动加 UTM 参数
4. 后台数据看板有专门的「合作伙伴导流」统计模块
