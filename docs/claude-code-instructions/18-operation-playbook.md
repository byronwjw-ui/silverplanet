# 第十八部分 · 第一个月运营执行手册

> 这一模块更偏运营而非开发，但需要让系统支持这些操作。

## 第一周（创建 + 测试）

### 主理人侧
1. 在管理后台填写品牌名、社群宣言、Slogan
2. 在管理后台创建话题库（第一版，10 个主题）
3. 邀请 20 位种子用户加入社群（手动后台添加用户）
4. 发布第一篇社群帖子（欢迎语）

### 朋友侧
1. 在管理后台注册账号，角色设置为 HELPER（叙事师）
2. 上传一份 sample 叙事信作为产品展示
3. 完成「人生回忆叙事」的素材收集清单模板

### 技术侧（已通过 Claude Code 完成）
1. 项目初始化
2. AI 陪聊跑通
3. 管理后台基础功能上线

## 第二周（社群启动）

### 主理人侧
1. 在管理后台发布第一个 AI 教学视频（用剪映数字人做，不出镜）
2. AI 语音机器人在种子群测试
3. 收集老人和子女对 AI 陪聊的反馈（管理后台有反馈表单）

### 系统支持
1. 用户反馈收集页面 `/feedback`
2. 学习内容发布功能
3. 数据看板展示 AI 陪聊的使用情况

## 第三周（付费转化）

### 主理人侧
1. 社群从免费转付费（19.9 元/月）
2. 推送付费提醒消息给免费试用快到期的用户
3. 收集第一位「人生回忆叙事」用户

### 系统支持
1. 订阅升级页面
2. 微信支付（或手动确认）
3. 自动到期提醒（cron 任务）

## 第四周（复盘 + 优化）

### 主理人侧
1. 数据复盘：付费会员目标 20-30 人，AI 陪聊付费用户 10-20 人
2. 制定第二个月计划
3. 复盘 AI 陪聊的对话质量

### 系统支持
1. 数据看板的复盘报告导出（PDF）
2. AI 对话质量评估页面（管理员可标注好/差的对话）
3. 系统稳定性监控
