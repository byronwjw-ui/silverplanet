# 第七部分 · 管理后台详细需求

## 7.1 管理后台总布局

左侧 sidebar + 右侧内容区，标准的后台管理布局。

### sidebar 菜单项

- 📊 数据看板 `/admin/dashboard`
- 👥 用户管理 `/admin/users`
- 💬 AI陪聊监控 `/admin/chat-monitor`
- 📝 社群内容 `/admin/content`
- 📚 学习内容 `/admin/learning`
- 🛒 订单管理 `/admin/orders`
- 🤝 志愿者管理 `/admin/volunteers`
- 📖 人生叙事 `/admin/narrative`
- ❤️ 公益项目 `/admin/charity`
- ⚙️ 系统设置 `/admin/settings`
- 🤖 AI陪聊配置 `/admin/ai-config`

### 顶部栏
- 当前管理员头像 + 姓名
- 退出登录
- 紧急预警提示（有未处理紧急消息时红点闪烁）

## 7.2 数据看板

核心数据卡片：
- 总用户数 / 本月新增
- 活跃用户数（7日活跃）
- 当前 AI 陪聊会话数
- 本月订阅收入
- 本月线下陪伴订单数
- 人生叙事订单数

图表：
- 近 30 天用户增长曲线
- 近 30 天 AI 陪聊使用时长
- 用户分布（角色、地域）
- 收入构成饼图

## 7.3 AI 陪聊配置页面（最核心）

这是「银发星球主理人」用来管理 AI 陪聊内容策略的页面。

### 话题库管理（CRUD）

- 列表展示所有话题，按分类筛选（daily / memory / health / entertainment）
- 添加新话题：标题、分类、开场白模板、追问列表、优先级、标签
- 编辑/删除话题
- 批量启用/停用
- 拖拽排序优先级

### 对话监控

- 实时查看当前活跃的聊天会话
- 显示：老人姓名、开始时间、消息数、最近情绪标签
- 可以点进去看完整对话记录（脱敏处理）
- 标记异常对话（如老人情绪持续低落）
- 紧急消息红色高亮

### 情绪预警

- 展示近 24 小时内情绪标记为 `sad` 或 `lonely` 的老人列表
- 主理人可以手动发起回访（标记为「需回访」）
- 回访后填写跟进记录

### 「银花」人格微调

不是改代码，而是改一些配置参数：

- 说话速度偏好（slow / normal / fast）
- 称呼偏好（阿姨 / 叔叔 / 您）
- 是否主动推荐社群（on / off）
- 节日特别祝福语开关
- 紧急关键词列表（可增删）
- 禁用话题列表（如某些用户不想聊家人）

## 7.4 用户管理

- 用户列表（表格），支持按角色、状态、注册时间筛选
- 搜索：姓名、手机号
- 查看用户详情：基本信息、订阅状态、聊天记录摘要、订单历史
- 手动添加用户（比如老人不会自己注册）
- 标记 VIP 用户
- 查看用户的紧急联系人信息
- 重置密码 / 解绑微信
- 软删除用户

## 7.5 社群内容管理

- 社群帖子列表，可以置顶 / 加精 / 删除
- 违规内容审核
- 学习内容管理（CRUD）：发布 AI 教学视频、教程文章
- 批量导入学习内容
- 内容分类与标签管理

## 7.6 订单管理

- 全部订单列表，按类型、状态筛选
- 订单详情：用户、金额、支付时间、服务详情
- 手动确认支付（线下转账场景）
- 手动退款
- 导出订单 Excel

## 7.7 志愿者管理

- 志愿者申请列表：审核通过 / 拒绝
- 志愿者列表：查看状态、服务次数、评分
- 匹配记录查看
- 强制下线异常志愿者

## 7.8 人生叙事订单

- 订单列表，按状态筛选
- 素材包查看与下载（语音、文字、照片）
- 朋友交付 PDF 上传
- 客户确认与反馈
- 朋友收入分成自动计算

## 7.9 公益项目

- 公益项目 CRUD
- 募集金额跟踪
- 合作伙伴标注（如侄女平台）
- 项目展示页样式预览
