# 第十九部分 · 适老化 UX 验收清单

## 视觉

- [ ] 所有正文文字 ≥ 22px
- [ ] 所有按钮文字 ≥ 24px
- [ ] 关键按钮高度 ≥ 60px
- [ ] 触摸目标 ≥ 48 × 48 px
- [ ] 文字与背景对比度 ≥ 7:1（WCAG AAA）
- [ ] 主色（暖橙 #FF9933）醒目但不刺眼
- [ ] 紧急按钮使用纯红色（#E53935）+ 白字
- [ ] 行高 ≥ 1.5
- [ ] 字符间距 ≥ 0.05em
- [ ] 段落间距明显
- [ ] 不使用浅灰文字（容易看不清）
- [ ] 图标必须有文字标签，不能只有图标

## 交互

- [ ] 按钮反馈明显（按下时颜色变深 + 轻微震动反馈）
- [ ] 长按不会触发意外操作
- [ ] 滚动不阻塞（流畅 60fps）
- [ ] 错误提示用大字 + 红色，居中显示，不用 toast
- [ ] 加载状态明显（loading spinner + 文字提示）
- [ ] 不使用悬浮（hover）效果，全部用 tap
- [ ] 表单字段大、间距大
- [ ] 输入框聚焦时键盘自动弹起
- [ ] 数字输入用大键盘
- [ ] 不使用滑动验证（容易卡）

## 语音

- [ ] 录音按钮巨大（≥ 120px 直径的圆形）
- [ ] 录音时有明显的视觉反馈（波纹 + 颜色变化）
- [ ] 录音上拉取消时有提示「松开发送，上拉取消」
- [ ] AI 回复语音自动播放
- [ ] 播放时可以暂停/重放
- [ ] 播放速度可调（0.8x / 1.0x / 1.2x）
- [ ] 音量按钮在最显眼位置

## 文案

- [ ] 不使用专业术语（如 "API"、"绑定"、"账号"）
- [ ] 用「您」称呼用户
- [ ] 错误提示像跟朋友说话（"哎呀，刚才没听清，您再说一遍？"）
- [ ] 成功提示有温度（"好嘞！银花记住了"）
- [ ] 引导文案口语化（"按住下面这个圆圆的按钮就能说话"）

## 内容

- [ ] 不使用阴森、负面、悲伤的内容
- [ ] 不主动提及衰老、死亡、疾病
- [ ] 不出现广告、弹窗、促销
- [ ] 不要求老人填写复杂表单
- [ ] 不强制实名认证（除非必要）

## 容错

- [ ] 即使老人点错按钮也能轻松返回
- [ ] 每个页面都有大大的「返回」按钮
- [ ] 关键操作（支付、删除）需要二次确认，确认弹窗用大字
- [ ] 操作失败时给出温和的提示和明确的下一步
- [ ] 不依赖网络的功能（如查看历史对话）支持离线

## 辅助功能

- [ ] 支持系统字体大小设置
- [ ] 支持系统深色模式（深色模式下用米色背景 + 深色文字）
- [ ] 支持屏幕阅读器（aria-label 完整）
- [ ] 支持键盘导航（Tab 键能到所有交互元素）
- [ ] 支持高对比度模式切换（在设置中）
- [ ] 字体大小四档可调（小/中/大/超大）

## 测试

- [ ] 找 3 位真实老人测试，记录他们的困惑点
- [ ] 在低配安卓机（红米/荣耀低端机）上测试
- [ ] 在 4G 网络下测试
- [ ] 在弱光环境下测试（屏幕亮度低）
- [ ] 戴老花镜测试
