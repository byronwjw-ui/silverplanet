# 第一部分 · 项目总纲

## 基本信息

- **项目名称**：银发星球 (Silver Planet)
- **一句话**：为老年人提供 AI 语音情感陪伴 + 社群服务的独立平台
- **Slogan**：**有人陪，有人懂**

## 目标用户

| 人群 | 年龄 | 核心痛点 | 我们的方案 |
|------|------|----------|-----------|
| 独居老人 | 65–85 岁 | 孤独、没人说话、怕出事没人知道 | AI 语音陪聊 + 社区互助 |
| 刚退休人群 | 50–65 岁 | 突然闲下来、觉得自己没用了、想学新东西 | 银发 AI 学习社群 |
| 老人的子女 | 30–50 岁 | 担心父母一个人在家、想尽孝但没时间 | 代父母购买 AI 陪聊 + 人生回忆叙事礼物 |

## 三个核心角色（人）

| 角色 | 谁 | 做什么 |
|------|------|------|
| **星主** | 项目主理人 | 运营社群、设计 AI 陪聊话题策略、管理志愿者网络、品牌建设 |
| **人生回忆叙事师** | 朋友（笔名匿名） | 老人讲故事，她写成 3000–5000 字深度叙事信 |
| **技术支持方** | 侄女 / 工程师朋友 | 提供 AI 语音相关技术咨询，不参与日常开发 |

> 在代码层面，**这三种角色都属于 ADMIN 或 HELPER 用户**，通过角色权限管理。

## 品牌定位

- **名称**：银发星球
- **Slogan**：有人陪，有人懂
- **色调**：暖橙（主） + 米白（背景） + 深绿（点缀）
- **风格**：极简 · 大字 · 大按钮 · 高对比度 · 适老化
- **归属**：独立品牌，不挂靠任何平台
- **气质**：温暖 · 安心 · 不商业 · 像家人
