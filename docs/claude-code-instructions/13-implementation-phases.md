# 第十三部分 · 分阶段实现顺序

## 阶段一：项目初始化（现在立刻做）

1. 初始化 Next.js 14 项目，配置 TypeScript + Tailwind
2. 配置 Prisma，根据模块 04 的 Schema 创建数据库
3. 配置 NextAuth.js（先用邮箱密码登录，微信后续加）
4. 创建 .env 文件，填入必要的 API Key
5. 搭建基础布局：
   - 落地页（简单的单页，先用占位内容）
   - 老人端 layout（大字模式）
   - 管理后台 layout（sidebar + 内容区）

完成标准：
- `npm run dev` 能启动
- 访问 `/` 看到落地页占位
- 访问 `/talk` 看到老人端骨架
- 访问 `/admin/dashboard` 看到后台骨架（重定向到登录）
- `npx prisma studio` 能看到所有表

## 阶段二：AI 陪聊核心功能（最优先）

1. 实现 lib/claude.ts（Claude API 封装 + 银花 System Prompt）
2. 实现 lib/tts.ts（文字转语音）
3. 实现 lib/asr.ts（语音转文字）
4. 创建 /api/chat/send 接口
5. 创建 /api/chat/session 接口
6. 实现老人端 /talk 页面（语音输入 + AI 回复 + 紧急按钮）
7. 测试完整对话流程

完成标准：
- 在 /talk 页面按住说话，能完成一次"听-说"循环
- 老人说出紧急关键词时，能触发紧急流程
- 数据库里能看到 ChatSession 和 ChatMessage 记录

## 阶段三：用户系统 + 管理后台

1. 完成注册登录流程（手机号 + 验证码）
2. 管理后台 - 用户列表
3. 管理后台 - AI 陪聊配置（话题库 CRUD + 对话监控）
4. 管理后台 - 数据看板（基础统计）

完成标准：
- 新老人可以通过手机号注册
- 管理员可以登录后台看到全部用户
- 管理员可以管理话题库、监控对话

## 阶段四：社群 + 订阅

1. 社群发帖/评论/点赞
2. 学习内容管理
3. 订阅系统（免费试用 14 天 → 付费）
4. 支付（先手动确认，后续接微信支付）
5. 老人端社群浏览页面

完成标准：
- 用户可以在社群发帖、评论、点赞
- 用户可以下单 19.9 元订阅
- 管理员手动确认支付后，用户订阅状态变为 ACTIVE

## 阶段五：线下互助 + 人生叙事

1. 志愿者申请/审核
2. 陪伴订单匹配
3. 人生叙事订单管理
4. 公益项目展示页

完成标准：
- 用户可以申请成为志愿者
- 用户可以下单陪伴服务
- 朋友可以登录后台上传人生叙事 PDF
- 公益项目页可以访问

## 阶段六：完善与部署

1. 全面测试
2. PWA 配置（让老人可以"添加到桌面"）
3. SEO 优化
4. 部署到 Vercel
5. 配置自定义域名

完成标准：
- 老人在手机上访问，可以"添加到桌面"
- 落地页 SEO 评分 90+
- 生产环境稳定运行
