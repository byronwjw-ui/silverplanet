# 第十部分 · 关键业务逻辑

## 1. AI 陪聊消息处理流程

```
老人说话（语音）
  ↓
前端录制音频
  ↓
上传到 /api/chat/send (multipart/form-data)
  ↓
后端调用 ASR 转文字
  ↓
检测紧急关键词（是→触发紧急流程）
  ↓
调用 Claude API（system prompt + 历史消息 + 当前消息）
  ↓
 AI 返回文字
  ↓
提取情绪标签 (detectEmotion)
  ↓
调用 TTS 生成语音 (并上传到 Storage)
  ↓
保存 ChatMessage 到数据库
  ↓
返回 { text, audioUrl, emotion, isEmergency }
  ↓
前端自动播放语音 + 显示文字
```

## 2. 紧急联络流程

```
检测到紧急关键词
  ↓
标记会话 & 消息 isEmergency = true
  ↓
查找用户的紧急联系人
  ↓
发送短信通知紧急联系人（腾讯云 SMS）
  内容：「【银发星球】您的家人 XXX 可能需要帮助，请立即联系。」
  ↓
在管理后台弹出紧急预警（WebSocket push）
  ↓
AI 回复安抚话术
  ↓
作为特别事件记录到 EmergencyLog（可选额外表）
```

## 3. 订阅过期处理（每日 cron）

```
每日凌晨 3:00 运行 (scripts/cron-subscription.ts)
  ↓
查询明天过期的订阅
  ↓
发送微信/短信提醒
  ↓
查询今天过期的订阅
  ↓
自动降级为免费版
  ↓
保留 7 天数据，之后清理（可配置）
```

## 4. 线下陪伴匹配逻辑

```
用户下单陪伴服务
  ↓
系统筛选匹配条件的志愿者
  │  • 服务类型包含
  │  • 空闲时间匹配
  │  • 距离（未来接入地理位置）
  ↓
推送通知给候选志愿者们（微信模板消息或短信）
  ↓
第一个接单的志愿者匹配成功
  ↓
双方收到确认信息（时间、地点、服务内容、联系方式）
  ↓
服务完成 → 系统推送双向评价
  ↓
评价完成 → 管理员电话回访老人
```

## 5. 人生叙事订单流转

```
子女/老人下单
  ↓ (状态：MATERIAL_COLLECTING)
我（或 AI 陪聊）收集素材
  │  • 录音故事
  │  • 老照片
  │  • 子女的问题
  ↓
素材上传完毕
  ↓ (状态：MATERIAL_READY)
通知朋友开始创作
  ↓ (状态：WRITING)
朋友上传成品 PDF
  ↓ (状态：DELIVERED)
客户确认或提出修改
  ↓ (状态：REVISING / COMPLETED)
朋友收入分成自动计算
```

## 6. 计费逻辑

### AI 陪聊使用时长计费

- 免费版：每天 30 分钟，超过后提示升级
- 升级版 9.9 元：每天 2 小时
- 升级版 29.9 元：不限时长 + 定制声音 + 优先响应
- Redis 记录每位用户当日使用时长，0:00 重置

### 推荐佣金计算

- 记录每个人生叙事订单的推荐人（`referrerId`）
- 订单状态变为 COMPLETED 后自动生成 `Commission` 记录
- 每月 1 号结算上月佣金

## 7. 限流与防滥用

- 同一手机号注册：每小时最多 3 次
- 同一 IP 注册：每小时最多 5 个账号
- 验证码：同一手机号每 60 秒最多 1 条，每小时最多 5 条
- AI 陪聊：每个用户每分钟最多 20 条消息
