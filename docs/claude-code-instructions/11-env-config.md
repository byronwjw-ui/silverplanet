# 第十一部分 环境变量配置

请创建 .env.example 文件，包含以下变量。

数据库：DATABASE_URL（postgresql 连接串）

NextAuth：NEXTAUTH_URL、NEXTAUTH_SECRET（至少 32 字符）

微信登录：WECHAT_APP_ID、WECHAT_APP_SECRET

Claude API：ANTHROPIC_API_KEY、ANTHROPIC_MODEL（claude-sonnet-4-5）、ANTHROPIC_MODEL_LIGHT（claude-haiku-4-5）

腾讯云：TENCENT_SECRET_ID、TENCENT_SECRET_KEY、TENCENT_ASR_APP_ID、TENCENT_TTS_APP_ID、TENCENT_SMS_APP_ID、TENCENT_SMS_SIGN_NAME（银发星球）、TENCENT_SMS_TEMPLATE_ID_VERIFY、TENCENT_SMS_TEMPLATE_ID_EMERGENCY

Azure TTS（备选）：AZURE_SPEECH_KEY、AZURE_SPEECH_REGION（eastasia）

Supabase Storage：SUPABASE_URL、SUPABASE_SERVICE_ROLE_KEY、SUPABASE_STORAGE_BUCKET_AUDIO（audio）、SUPABASE_STORAGE_BUCKET_NARRATIVE（narrative-pdfs）、SUPABASE_STORAGE_BUCKET_PHOTOS（photos）

Redis：KV_URL、KV_REST_API_URL、KV_REST_API_TOKEN、KV_REST_API_READ_ONLY_TOKEN

微信支付：WECHAT_PAY_MCH_ID、WECHAT_PAY_API_KEY、WECHAT_PAY_APP_ID、WECHAT_PAY_NOTIFY_URL、WECHAT_PAY_CERT_PATH、WECHAT_PAY_KEY_PATH

站点配置：NEXT_PUBLIC_SITE_URL、NEXT_PUBLIC_SITE_NAME（银发星球）、ADMIN_EMAIL

监控（可选）：SENTRY_DSN、SENTRY_AUTH_TOKEN

特性开关：FEATURE_WECHAT_LOGIN（true）、FEATURE_WECHAT_PAY（false）、FEATURE_EMERGENCY_SMS（true）、FEATURE_VOICE_FALLBACK_BROWSER（true）

## 说明

1. .env.example 仅占位，不要提交真实密钥
2. 本地开发使用 .env.local（已加入 .gitignore）
3. 生产环境在 Vercel 仪表盘配置
4. NEXT_PUBLIC_ 开头的变量会暴露给浏览器，不放敏感信息
5. 用 zod 在 lib/env.ts 中验证环境变量
