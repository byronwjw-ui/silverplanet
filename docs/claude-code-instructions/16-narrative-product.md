# 第十六部分 · 人生回忆叙事产品规范

## 产品定义

老人的子女或老人自己预约 → 主理人或 AI 陪聊收集老人的故事素材（语音录音 + 几个关键问题） → 朋友（人生回忆叙事师）收到素材 → 与 AI 协作写成 3000-5000 字「人生回忆信」 → PDF 交付，如同一本微型自传的第一章。

## 和普通版「镜中人」的区别

| 维度 | 普通版镜中人 | 银发版人生回忆叙事 |
|------|--------------|---------------------|
| 素材来源 | 用户主动填问卷 | AI 陪聊的录音转文字 + 主理人做的前端访谈 |
| 叙事主题 | 星盘 / 符号 / 心理原型 | 人生历程 / 家庭故事 / 时代记忆 |
| 交付对象 | 本人 | 本人或子女（作为礼物） |
| 语言风格 | 诗意、洞察 | 平实、温暖、像一封家书 |

## 定价

- 个人版：980 元
- 家庭版：1980 元（含多人故事 + 照片集）

## 朋友的工作流（系统侧需要支持的功能）

1. **收到订单和素材包**
   - 后台显示新订单待处理
   - 一键打开素材包页面

2. **素材包内容**
   - 老人基本信息（姓名、年龄、哪里人）
   - AI 陪聊中录下的 3-5 段故事（已转文字）
   - 子女补充：最想了解父母哪段人生
   - 老照片 1-3 张（可选）

3. **朋友创作（系统外，2-3 天）**
   - 通读素材，提取最动人的片段
   - 设计叙事结构：童年 → 青年 → 中年 → 现在 → 对子女的话
   - Claude 协作扩展润色，朋友注入温度和洞察

4. **交付**
   - 后台上传 PDF（封面 + 3000-5000 字叙事信 + 老照片）
   - 系统通知子女/老人下载

5. **反馈**
   - 客户填写满意度评分（1-5 星）
   - 客户可以发起一次免费修改

## Sample 叙事信任务（给朋友的测试任务）

用以下虚构老人故事，写一份 sample 叙事信（2000 字即可）：

- 王秀兰，女，1938 年生，山东人
- 年轻时是纺织工人，后来工厂改制下岗
- 丈夫 60 岁去世，独自把两个孩子供到大学
- 现在 82 岁，独居，每天去公园喂猫
- 子女最想问：「妈这辈子最骄傲的是什么？有什么遗憾？」

sample 写好后保存在 `docs/sample-narrative.pdf`，作为对外销售的展示物料。

## 系统侧的素材收集功能

在管理后台 `/admin/narrative/orders/[id]/materials` 页面，主理人可以：

1. 从 AI 陪聊会话中**勾选**对应老人的精彩片段，一键加入素材包
2. 手动添加文字访谈记录
3. 上传老照片
4. 填写子女的问题清单
5. 一键标记「素材就绪」，通知朋友

## 推荐分成

- 朋友拿 85-90%
- 主理人拿 10-15%（作为前端导流和素材收集的报酬）
- 自动在 Commission 表中记录
- 每月 1 号统一结算
